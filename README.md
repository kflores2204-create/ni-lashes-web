# NI Lashes Studio - Web & Ecommerce Platform

Plataforma web oficial para **NI Lashes Studio**, centro especializado en diseño y estética de la mirada (extensiones de pestañas, lifting y laminado de cejas).

## Características
- **Catálogo de Servicios y Productos:** Con cálculo detallado de IGV (18%) y gestión de stock.
- **Sistema de Citas Online:** Selección de fecha, horarios disponibles y confirmación instantánea.
- **Integración con WhatsApp:** Atención directa en el número oficial +51 997 448 945.
- **Panel Administrativo Oculto:** Acceso mediante `#admin` con PIN de seguridad.

Desarrollado con React, Vite y Tailwind CSS.
